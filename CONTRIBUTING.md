# Contributing

1. Read `AGENTS.md`, `docs/CONTRACT.md`, and `docs/THREAT_MODEL.md`.
2. Open an issue for substantial design changes.
3. Add tests for positive, negative, boundary, and failure behavior.
4. Run `python tools/starter_build.py` and `python -m unittest discover -s tests -v`.
5. Update the contract, schemas, capabilities, and compatibility metadata together when interfaces change.

Do not submit credentials, private keys, private operational information, or unlicensed material.
